# Créditos

`gedankenpalast_cosmos.glb` se genera con `tools/build_cosmos_glb.py` a partir de dos modelos de Sketchfab, ambos con licencia [CC-BY-4.0](http://creativecommons.org/licenses/by/4.0/). El script combina los dos modelos, los reescala y remodela la nube de puntos en los 4 caminos del grafo.

| Modelo | Autor | Fuente |
|---|---|---|
| Alien Space Nebula 2 (Skybox) | Jungle Jim | https://sketchfab.com/3d-models/alien-space-nebula-2-skybox-a1c688c6e8164fd4ad5a7e56047e8b50 |
| Need some space? | Loïc Norgeot | https://sketchfab.com/3d-models/need-some-space-d6521362b37b48e3a82bce4911409303 |

## Ideas adaptadas

Las neuronas en JSON, el inyector, las sinapsis propuestas con motivo y los laboratorios de Python que se ejecutan en el navegador (Pyodide) adaptan ideas de [Proyecto Alejandría](https://github.com/MarioGreks/proyecto-alejandria), de Mario Torralba, bajo licencia MIT. Es una reimplementación propia para una web estática; no se ha copiado su código.
Pyodide (MPL-2.0) se descarga desde jsDelivr solo cuando se pulsa «Ejecutar».
